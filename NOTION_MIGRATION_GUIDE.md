## Instructions pour obtenir les IDs de bases Notion

Une fois que vous aurez créé ces 8 bases de données dans Notion :

1. **Ouvrez chaque base de données** dans Notion
2. **Copiez l'URL** de la page (elle ressemble à : `https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)
3. **L'ID de la base** est la partie entre le dernier `/` et le `?` (si présent)
   - Exemple : `https://www.notion.so/29efaf44a5f280de95cccd8ddb555923` → ID = `29efaf44a5f280de95cccd8ddb555923`

4. **Partagez vos bases avec l'intégration Notion** :
   - Ouvrez chaque base
   - Cliquez sur `•••` en haut à droite
   - Sélectionnez `Add connections`
   - Recherchez votre intégration (celle qui a la clé API `YOUR_NOTION_API_KEY`)
   - Confirmez

Ensuite, ajoutez ces IDs dans votre fichier `.env` :

```env
# IDs existants
NOTION_API_KEY=YOUR_NOTION_API_KEY
NOTION_PROJECTS_DATABASE_ID=29efaf44a5f280de95cccd8ddb555923
NOTION_BLOG_DATABASE_ID=29efaf44a5f2803c84b7d03f093438a7

# Nouveaux IDs à ajouter
NOTION_PERSONAL_INFO_DATABASE_ID=xxxxx
NOTION_SOCIAL_LINKS_DATABASE_ID=xxxxx
NOTION_WORK_EXPERIENCE_DATABASE_ID=xxxxx
NOTION_EDUCATION_DATABASE_ID=xxxxx
NOTION_SKILLS_DATABASE_ID=xxxxx
NOTION_TIMELINE_DATABASE_ID=xxxxx
NOTION_ACHIEVEMENTS_DATABASE_ID=xxxxx
NOTION_INTERESTS_DATABASE_ID=xxxxx
```

Une fois que vous aurez créé vos bases et récupéré les IDs, je pourrai modifier le code pour récupérer automatiquement toutes ces données depuis Notion !
